# DIMACS CNF to ACTS Converter

This program converts Boolean satisfiability formulas in DIMACS CNF format to ACTS (Advanced Combinatorial Testing System) input model format.

## Building the program

To build the converter, run the following commands from the project root:

```bash
mkdir -p build
cd build
cmake ..
make
```

This will produce the executable binary `dimecs_to_acts_converter`.

## Usage

```bash
./dimecs_to_acts_converter [--strength <t>] [--keep-aux] <cnf_file> <output_file>
```

### Arguments:
* `<cnf_file>`: Path to the input DIMACS CNF file.
* `<output_file>`: Path to write the output ACTS model file.
* `--strength <t>`: Write a `[Relation]` section of strength `t`, which contains all variables except auxiliary ones (see below). Use it with `citcpp cagen --doi -1`, so that only the variables in the relation have to be covered. Without this option, no `[Relation]` section is written.
* `--keep-aux`: Do not detect auxiliary variables, i.e. the relation contains all variables.

## Mapping details
* Each CNF variable $i$ is mapped to a parameter in ACTS. If the file contains a variable naming comment `c <i> <name> ...` (or `c <i>$ <name> ...`) and `<name>` is a valid ACTS identifier not used by another variable, the parameter is named `<name>`. Otherwise it is named `pi`.
* Since CNF variables are Boolean, they are represented as integer parameters in ACTS with the domain `0, 1` (representing false and true, respectively).
* Positive literals $i$ are mapped to `(pi = 1)`.
* Negative literals $-i$ are mapped to `(pi = 0)`.
* Each CNF clause is mapped to a disjunction constraint in ACTS.

## Auxiliary variables
CNF files of the Linux kernel variability analysis (e.g. generated by kconfigreader or LVAT) contain auxiliary variables, which were introduced by the transformation to CNF (Tseitin variables). They are marked with a `$` after the variable index and are named `_X<n>`, `_X<n>_m` or `x<n>`, e.g.:
```
c 3146$ _X2
c 5703$ x2
```
These variables remain parameters of the ACTS model, since they are part of the constraints. However, they are not included in the `[Relation]` section, since their values are determined by the other variables. Variables marked with `$` but having other names (e.g. in `freebsd-icse11.cnf`) are not considered auxiliary.
